# BLOCKERS

阻塞項與它們實際擋住什麼。

規則：一條阻塞要寫清楚「擋住哪個具體交付」。擋不住任何東西的不叫阻塞，
那叫待辦，不要寫在這裡。

---

## B-01　拿不到 Context 內容

**擋住：** 十四題的第 1、2、3 題（Context 有多少、多少有效、多少污染）。
也擋住整個 Context 健康那一層。

**原因：** Claude Code 的 hook 只給工具事件，看不到 context window 裡裝了什麼。

**解法：** 接 Code Duo 的 Context Token Monitor（見 ADR-002）。
需要知道那邊的介面長什麼樣、拿得到哪些欄位。

**現況：** 未開始。需要她提供 Code Duo 那邊的接口資訊。

**不要做的事：** 不要自己估一個 token 數來填。拿不到就是拿不到。

---

## B-02　hook 是否真的在 Claude Code 啟動時載入，從未驗證

**擋住：** 所有即時採集的前提。如果 hook 根本沒被載入，
事件帳本永遠是空的。

**原因：** hook 生效與否取決於 session 啟動當下的工作目錄。
事後 `cd` 進 repo 跑指令不等於在那裡開 session。

**解法：** 在 `/Volumes/NewDrive/AI Project/Forseti` 底下開一個新 session，
隨便寫個檔，看 `.forseti/state.json` 有沒有出現。
現在它裡面還會多一份 Evidence Receipt。

**現況：** 已經跨三輪未驗證。只有她能做這件事。

## B-03　Python 版本是 3.11.5，工程書要求 3.12

**擋住：** 目前擋不住任何東西。`forseti doctor` 用標準庫就夠。

**原因：** 這台機器的 python3 是 anaconda 的 3.11.5。

**解法：** 階段 1 需要 Pydantic v2 的時候再處理，可能是建 venv 裝 3.12。

**現況：** 記著，不急。列在這裡是因為工程書寫了 3.12，
避免下一個 session 以為可以直接用 3.12 的語法。

## B-04　工程書只讀了三成

**擋住：** 階段 1 與階段 4。

**原因：** 157,680 字，2026-09-08 那輪只讀了第 0 到 10 節加 Phase 清單。
Phase 1-12 的細節沒讀。

**解法：** 動階段 1 之前補讀工程書 Phase 1-2。
詳細對照見 `REQUIRED_READING.md` 的補讀門檻表。

**現況：** 已知，已排入門檻檢查。

---

## B-05　字串比對類訊號不可用，但還沒有替代方案

**擋住：** 任何需要「這句話有沒有在宣稱某件事」的判斷。

**原因：** 2026-09-08 在 40 個 healthy session 上實測，
`SCOPE_EXPANDING_TERMS` 每千則命中 242 次、40/40 session 全中；
抽樣看內容，假陽性有五種結構，其中一類方向是反的
（明確區分「我驗過的」與「我沒驗的」的 agent 會命中更多次）。

**解法方向：** 階段 2 的 Claim 抽取要用結構規則
（路徑、數字、過去式動詞、引號），抽不出來就標 UNEXTRACTABLE，不猜。
不要靠加長詞表解決，那不是詞表長度的問題。

**現況：** 已知限制，已寫進 `claims.js` 與 `rhetoric.js` 的定義處並有測試守著。

## B-06　「UNSUPPORTED 後接強烈反應 3.8 倍」這個數字不能用

**擋住：** 任何拿它當根據的推論。

**原因：** 沒有分開「AI 自己走掉」與「她的指令本來就模糊」。
見 ADR-004。

**解法：** 階段 3 做完人的訊息分類之後重算。

**現況：** 已標記為不可用。不要在任何報告裡引用它。

---

## B-07　階段 0 的出口條件沒有被真的驗證過

**擋住：** 階段 0 從 `IN_PROGRESS` 進到 `VERIFIED`。

**原因：** 出口條件是「開一個全新 session，只給 repo 路徑，不給任何口頭說明，
它跑完 `forseti doctor` 能講出北極星、當前階段、必讀缺什麼、有哪些阻塞」。
指令本身寫完了、16 條測試過了，但那是我自己在這個 session 裡測的。
我已經知道答案，所以我測不了「一個不知道答案的人能不能靠它知道」。

**解法：** 她在這個 repo 底下開一個新 session，只說「跑 forseti doctor」，
看那個 session 講不講得出那四件事。

**現況：** 只有她做得到。與 B-02 是同一類。

**不要做的事：** 不要因為測試通過就把狀態改成 VERIFIED。
工程書 AI-04：WRITTEN 跟 VERIFIED 是不同狀態，不准跳。
